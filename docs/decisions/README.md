# Architecture Decision Records

Each ADR documents one significant decision, using the template in [`0000-template.md`](0000-template.md).

**Status values:** `Proposed` → `Accepted` → (`Superseded by ADR-XXXX` | `Rejected`)

Unresolved questions live in [`../open-questions.md`](../open-questions.md). When a question is answered, it
is closed there and the outcome is recorded in an ADR (new or amended).

- **Question:** Should the web UI have a way to copy an issue's reference (for example `SHOP-a178e3b`) or its
  full 12-character id, so it can be pasted into the CLI, a commit message or a pull request? Where should it
  live (the issue drawer, a hover action on cards and backlog rows), and which value should it copy by default?
- **Things to weigh:**
  - Copying uses the browser clipboard, which is allowed on `localhost` / `127.0.0.1`. It needs no server
    change, only a short "Copied" confirmation.
  - On cards and rows the control must not also open the issue, and it must be reachable by keyboard.
  - The short reference is what people type and what the skill tells agents to use; the full id is what
    `issue delete` requires.
- **Recommendation:** Yes. Put a copy button next to the reference in the drawer and show it on card and row
  hover. Clicking copies the short reference (`KEY-shortid`); the drawer also offers "Copy id" for the full id.
  No new core operation is needed.
- **Decision / date:** Yes, as recommended, but a single copy icon next to the reference that copies the short
  reference; no separate "Copy id" button. 2026-11-21 (PR #4)

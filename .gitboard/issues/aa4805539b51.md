## Goal

Show an issue's change history on its issue page in the web UI, so a reader can see who changed what and when without leaving Gitboard.

## Scope

- [ ] A "History" section (or tab) on the issue page listing the commits that touched the issue file, newest first: author, date, commit subject and short hash.
- [ ] Per entry, show what changed (status, title, labels, body) as a readable diff of the issue file, collapsed by default.
- [ ] Read the history from git (`git log --follow` on the issue file); no separate store.
- [ ] A core function and a server endpoint that return the history, so the CLI can reuse it later (for example `gitboard issue history <ref>`).
- [ ] Paginate or lazy-load long histories.
- [ ] Handle issues with no commits yet (uncommitted or new) and repositories with shallow clones.

- **What:** per-user Git credentials for hosts that have no adapter: an app-generated ed25519 SSH key per user (public key shown to add at the remote), pasted HTTPS tokens, an opt-in shared team credential, and the SSH host key policy (instance-managed `known_hosts`, trust on first use confirmed by an admin, strict afterwards).
- **Why deferred:** the MVP uses the OAuth token from the GitHub login as the only Git credential. When this is built, no user-controlled value may enter `GIT_SSH_COMMAND` (see the accounts ADR).

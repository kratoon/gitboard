- **Question:** Is the per-user profile (remotes, preferences, personal saved views, commit identity) required to be a Git repository, and may the local CLI adopt it as its registry? Is the proposed split of settings right?
- **Why it matters:** It decides where each setting lives and whether per-user configuration is portable between instances and devices. A format decision (`profile.yaml`, new optional `branch` key in the repository config) is hard to change once users have data.
- **Options:** Profile as Git-backed repository, as an instance-local file, or both with the same schema. CLI: keep `repos.json`, or adopt the profile later via a `gitboard profile` command. Split: repository (projects, columns, views offered, default Gitboard branch), profile (repositories, per-user branch override, visible projects, default repository, view, theme, personal saved views, identity), instance (listen address, auth, limits, allowed remote hosts), secrets (never in Git).
- **Recommendation:** Optional, Git-backed or local with the same schema; CLI adoption later. Adopt the split above. Shared saved views, if built, live in `.gitboard/config.yaml` (FEAT-cd7b875); personal ones in the profile.
- **Related:** FEAT-8c2e32c, ADR-7d58e8b, FEAT-cd7b875
- **Decision / date:** 2026-11-21. MVP: the profile is an instance-local file, per workspace (one workspace, `default`), on each side: the hosted instance has its own, and the local app keeps its existing registry (`repos.json`) and browser preferences. The schema is designed to work for both backings (no secrets, no machine paths, remotes in canonical form). The Git-backed profile and sharing one repository list between the local app and the hosted app are deferred (FEAT-31d4843). The split of settings is adopted: repository (`.gitboard/config.yaml`: projects, columns, views offered, `branch`), profile (repositories and remotes, per-repository `branch` override, visible projects, default repository, view, theme, personal saved views, commit identity), instance (listen address, public URL, GitHub App credentials, limits, allowed remote hosts, master key location), secrets (never in Git). Recorded in ADR-7d58e8b.

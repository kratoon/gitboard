- **Question:** Which optional extras do we build, and when?
- **Why it matters:** Each is useful but not needed for the first release; recording them keeps the first release small.
- **Options:** Optional webhook endpoint with a per-repository secret; cross-repository views and search (fan-out with caps, or a derived rebuildable index under the admission criteria of the no-database ADR); how hosted and local users share a repository (plain Git semantics, plus documentation); `repo.add` of local paths stays CLI-only (initialising a repository from the hosted UI is MVP scope, see FEAT-0a956bc).
- **Recommendation:** Defer all of these. Webhooks are an acceleration only; the system is correct with polling alone.
- **Related:** FEAT-8c2e32c, ADR-fe71de9, ADR-099d4df
- **Decision / date:** _pending_

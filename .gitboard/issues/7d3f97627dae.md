## Problem

The issue preview does not render some Markdown lists correctly.

Example: ADR-87400e0 ("Accounts, sessions and per-user Git credentials for self-hosting"). Under **Login and identity** the numbered list 1 to 7 renders as a list. The numbered lists that follow (8 to 12 under **Credentials and authorisation**, **Injection and hardening**, and 13 to 16 under **Deployment requirements**) render as plain paragraphs.

## Likely cause (to verify)

In the source, each group is a bold line directly followed by a list with no blank line, and the list continues the numbering (starts at 8, 11 or 13). In CommonMark a list can interrupt a paragraph only if it starts with `1.`, so lists starting at another number are folded into the paragraph. The first group starts at 1, which is why it works.

## Expected

Numbered lists render as lists regardless of their start number or a missing blank line before them, or the renderer's behaviour is deliberately documented.

## Steps to reproduce

1. Open ADR-87400e0 in the web app.
2. Compare the list under "Login and identity" with the lists under the later bold headings.

## To check

- Which Markdown renderer and options the web app uses (GFM, breaks, start-number handling).
- Whether other issues are affected (search bodies for a bold line directly followed by a non-1 numbered item).
- Whether to fix the renderer, normalise on display, or only fix the ADR source.

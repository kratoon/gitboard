- **Question:** How is `gitboard serve` packaged and which platforms and versions are supported?
- **Why it matters:** The point of the project is that anyone can host it, including on a NAS with unusual SSH and container environments.
- **Options:** npm package only; npm plus a multi-architecture container image; vendor notes for Synology and QNAP. Minimum Node and Git versions, checked at startup.
- **Recommendation:** Ship the container image next to the npm package, check the Git version at startup (keep Git patched), and document reverse proxy and NAS setups.

## Goal

Show a small coloured icon for the issue type wherever an issue appears, like Jira: purple for epics, green for stories and blue for tasks.

## Background

FEAT-130c757 added a border in the type's colour to preview links (`KEY: title`): epic `--type-epic` (purple), story `--type-story` (green). The CSS also defines `--type-task` (blue), but there is no `task` type yet: `ISSUE_TYPES` in `src/core/types.ts` is `story | epic`.

## Scope

- [ ] One icon component, one icon per type, using the same three colours as the borders; usable at small sizes and in light and dark themes.
- [ ] Show it on board cards, backlog rows, the drawer and issue page header, the epics sidebar, the child-issue table (next to the Ref) and preview links.
- [ ] Add an accessible name or tooltip with the type, so colour is not the only signal.

## To decide

- Whether to add a `task` type (blue), which touches the schema, the CLI (`--type`), the board and the docs, or to leave the blue colour for later. Needs its own ADR if added.
- Whether the icon replaces the type chip in the drawer header or sits beside it.

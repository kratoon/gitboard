- **Intent:** Track our decisions in Gitboard itself (dogfooding).
- **Decision / date:** 2026-11-14. The ADRs moved from `docs/decisions/` into the `ADR` project of this
  repository's `.gitboard/`, using only the CLI. Each is an issue titled by the decision itself; the status is the
  column (`proposed`, `accepted`, `superseded`, `rejected`, a project-level column override per ADR-c680df6);
  sibling links became plain `ADR-<id>` references. The template and the index file were dropped (the
  `ADR` board is the index; the template is described in the README). Open questions stay in this file.

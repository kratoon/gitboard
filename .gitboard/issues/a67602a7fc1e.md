- **What:** one shared bare object store per remote and a `git worktree` per user, to save disk and fetches (the option declined for the MVP in FEAT-02f3376).
- **Trigger:** Phase 0 or production measurements show clone duplication matters.
- **Rules if built:** a worktree only ever moves to a commit that the user's own credential just proved it can see; per-user refs in the store; no credentials in the store's config; revocation deletes the user's worktree; maintenance under a per-store lock with automatic gc off; one choke point (`acquireView(user, remote)`) with cross-user leak tests.

- **Related:** FEAT-8c2e32c, FEAT-cd25599

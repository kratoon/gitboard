- **Goal:** prepare core for per-user hosting without changing any local behaviour.
- **Includes:** an explicit resolver context (registry source and clone directory) instead of process-global `userDirs()`; hardened `runGit` defaults (no global or system config, hooks disabled, protocol restrictions, timeouts); HTTPS remotes with an allowed-hosts list and private-address blocking, only in hosted mode; hosted clone options (blobless, sparse `.gitboard/`); `core/git/sync.ts` (fetch, fast-forward, commit only `.gitboard/`, push, reset to remote, trailers); an opt-in `gitboard sync` for CLI users; a summary projection for board and backlog responses (see the dedicated issue).
- **Depends on:** phase 0 results; ADR-0aa6b23.
- **Validation milestone:** all existing tests and the parity test unchanged; new sync tests against a local bare remote.

- **Related:** FEAT-8c2e32c, ADR-819be48

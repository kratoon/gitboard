- **Goal:** something a stranger can install on a NAS from the instructions.
- **Includes:** admin commands, quotas, backup and restore, upgrade path, reverse-proxy and single-sign-on instructions, metrics, log redaction, container image for the supported architectures.
- **Packaging (FEAT-f5a9856):** `linux/amd64` and `linux/arm64` images on GitHub Container Registry built in CI and published on release, Node 22, a current patched Git with a startup minimum-version check, weekly and security-release rebuilds, no SSH client, container marker and the unsupported-outside-container warning and flag.
- **Sharing with local users:** the operator documentation includes the guidance for repositories used from both a local checkout and the hosted app (pull before pushing `.gitboard/` changes; `rank` and the config file are the usual conflict spots).
- **Operator documentation:** `docs/` is written as the feature ships, in the present tense. It opens with the risks, requirements and quotas for running in Docker (the only supported deployment), exactly as recorded in ADR-87400e0, and says that running outside a container is unsupported.
- **Depends on:** phase 2-3.
- **Validation milestone:** fresh install on a NAS from the documentation; restore from backup; malicious-URL and credential-leak tests pass.

- **Related:** FEAT-8c2e32c, ADR-819be48

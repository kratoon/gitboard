## Scope

- [ ] Issue keys in the epics sidebar names are preview links. The names are buttons today; a link cannot sit inside a button, so the markup needs to change.
- [ ] The issue title can show preview links: read-only text with links that switches to the input when clicked or edited.
- [ ] Issue keys that belong to another repository: decide whether to link them (the address is portable, so `/repos/<slug>/issues/<issue key>` could work if that repository is registered) or leave them as text.

- [ ] Confirm in the browser the checks PR #8 left open: reload on an issue page, a pasted issue page URL in a new tab, and two registered repositories that share `owner/name` on different providers (provider prefix in the address).

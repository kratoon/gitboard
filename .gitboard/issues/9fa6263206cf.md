- **Goal:** `gitboard serve` for several users on one instance.
- **Includes:** accounts and sessions; credential store; per-user managed clones; per-clone lock, commit, push, retry by re-executing the operation; adaptive polling and cross-user notification; SSE; instance-local profile; container image.
- **Depends on:** phase 1; decisions on clone layout, authentication, credentials, settings split, board branch.
- **Validation milestone:** two users on one instance and one remote see each other's edits within seconds; an external `git push` appears via polling; killing the process during a write loses nothing that was acknowledged; user A cannot reach user B's repositories.

- **Related:** FEAT-8c2e32c, ADR-819be48

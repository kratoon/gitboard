# Agent instructions

## Commit messages

Use Conventional Commits: `feat(scope): short description`. If a Gitboard issue is involved, add its
reference: `feat(scope): FEAT-a3f91c2 short description`.

## Finishing an issue

When the work for a Gitboard issue is done and the PR is open, set it to `done`
(`gitboard issue move <ref> done`). First check the issue for anything still pending (undecided
questions, unchecked checklist items, follow-ups) and resolve it or record it in the issue.
